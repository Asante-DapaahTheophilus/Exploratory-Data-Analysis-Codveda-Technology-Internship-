# Sales Data Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a sales dataset using Python. The main objective was to clean, analyze, visualize, and extract meaningful business insights from the data to support data-driven decision-making.

The analysis covered customer purchasing behavior, regional sales performance, product category trends, sales representative performance, sales channels, profit analysis, and correlations between numerical variables.

---

## 📂 Dataset Features

The dataset contains the following columns:

- product_id
- sale_date
- sales_rep
- region
- sales_amount
- unit_cost
- unit_price
- quantity_sold
- product_category
- customer_type
- sales_channel
- sales_rep_and_region

##  EDA Processes Performed

- Statistical summary of the dataset
- Distribution analysis
- Outlier detection
- Correlation analysis

###  Visualizations Created
- Histograms
- Scatter Plots
- Boxplots
- Bar Charts
- Line Plots
- Correlation Heatmap

##  Key Business Insights

- Identified the top-performing regions by sales revenue
- Analyzed which product categories generated the highest sales
- Examined relationships between unit price, quantity sold, and sales amount
- Evaluated sales representative performance
- Analyzed monthly sales trends
- Detected outliers and unusual sales patterns
- Compared customer types and sales channels
